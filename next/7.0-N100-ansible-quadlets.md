# N100 ansible + rootless quadlets (7.0)

## Goal

- N100 headless Fedora bootc accepts ansible SSH as `nimda`, key only.
- Ansible in `../ansible-deblab` deploys rootless podman quadlets, no system quadlets baked.
- SELinux stays enforcing. No permissive, no custom policy unless AVC proves unavoidable.
- sudo stays deleted. Privilege via `run0` + polkit only.

## Decisions (locked)

- User: static `nimda` via sysusers, not homed firstboot.
- Auth: SSH key only. Pubkey source open (build-arg vs `krw` console inject vs ignition).
- Become: `community.general.run0`, not sudo.
- Quadlets: rootless user scope, `loginctl enable-linger nimda`.

## Current state

- Recipe `recipes/krw-N100.yml` = `base/all` + `cpu/intel` + `finalize/all`.
- `recipes/base/clean.yml` removes `openssh-server`. `recipes/base/systemd-services.yml` masks `sshd.service` + `sshd.socket` repo-wide.
- `recipes/finalize/container.yml` + `removesuid.sh` delete `/usr/bin/sudo /usr/bin/su /usr/bin/pkexec`. Privilege = `run0` only.
- User creation = interactive `/usr/bin/firstboot` (`homectl create`, hardcoded `lgranie`). No headless path, no `nimda`, no keys.
- `python3` absent from recipes. Ansible needs it.
- Firewall `files/base/network/etc/firewalld/zones/Kierownik.xml` deny-by-default, no `ssh` service.
- `podman.socket` user-only. Zero quadlets on N100.
- Base image `quay.io/fedora/fedora-bootc:44` enforcing/targeted. Repo has no `setenforce/permissive`, no `/etc/selinux/config` overlay.
- ansible-deblab expects `nimda` + key + `python3` + `sudo` (`group_vars/all.yml`, `ansible.cfg` `remote_user=nimda`, `become_method=sudo`). Zero SELinux handling (no `semanage/restorecon/:Z/seuser`).

## SELinux gap (Debian -> Fedora)

P0, breaks now:

- `apt` everywhere (`deblab.podman/tasks/main.yml:3`, `deblab.lan`, `deblab.nas`, `debian.update`). Bootc `LockLayering=true` forbids runtime layering. Move packages to recipe.
- Bind `hostPath` unlabeled, no `:Z`: `/media/*`, `/mnt/1T 2T_*`, `/etc/localtime`, pihole `/root/data/pihole`, `/dev/dri /dev/snd /dev/net/tun`. Needs `sefcontext` + `restorecon` host side, or named volumes.
- File copy no context: `roles/deblab.podman/tasks/pod.yml:69-104`, `/etc/exports`, `/etc/systemd/system/*`, udev rules. Add `setype` + `restorecon`.
- Firewall mismatch: ansible raw `iptables` netns (`roles/deblab.lan`, `inventories/system/group_vars/deblab-routing.yml`). Kierownik `firewalld` zone `Kierownik` blocks all pod `hostPort`s. `files/wm/8745/etc/sysctl.d/70-bridge.conf` `bridge-nf-call-iptables=0` bypasses iptables. Use `ansible.posix.firewalld` per app.
- Network fight: `roles/deblab.lan/tasks/network/networkd.yml` enables `systemd-networkd`, deletes `/etc/network/interfaces`. Kierownik is NetworkManager. Skip LAN network tasks on N100.

P1, wrong assumptions:

- Hardcoded `/home/*` (`pod.yml:21,25`, `runner.yml:11`). Real path `/var/home`. Wrong context + homed clash.
- Pihole `/root/data` = `admin_home_t`, tiny `/root`. Move to `/var/lib/pihole`.
- `/usr/local/lib/systemd/...` (`podman/tasks/main.yml:34-48`) on read-only `/usr`. Use `/etc/systemd/...` or `~/.config/systemd/user`.
- `UserNS=host` default (`pod.yml:110,116`) kills MCS isolation. Keep `auto`, `host` only for passthrough.

Already OK: no ufw/apparmor in roles, named volumes need no relabel, `stat unprivileged_userns_clone` guarded, `systemd_service`/`enable-linger`/`ansible.posix.mount` translate 1:1.

## Design (preference order)

1. N100-only overlay. Never touch `base/`. New `recipes/n100/server.yml` + `files/n100/`, include from `krw-N100.yml` after `base/all`.
2. Reinstall `openssh-server` + `python3` in N100 module. Unmask + enable `sshd` there (override base mask).
3. `nimda`: `usr/lib/sysusers.d/nimda.conf` (`u nimda 1000:1000`), `usr/lib/tmpfiles.d/nimda.conf` (`d /var/home/nimda 0700`), subuid/subgid `524288:65536`, linger preset, `authorized_keys` from build-arg (never commit key). Console `krw` task as fallback injector.
4. run0-only: polkit rule wheel passwordless `run0` for `nimda`. Ansible `ansible_become_method=community.general.run0`, `ansible_become_exe=run0`, `pipelining=false`.
5. Quadlets: image ships none. Ansible `deblab.podman` writes `~nimda/.config/containers/systemd/`. Image prepares linger, user `podman.socket` (already), storage defaults, `fcontext` for `/mnt/* /var/lib/pihole /var/home/nimda/.config/containers`.
6. Firewall: `firewall-offline-cmd --zone=Kierownik --add-service=ssh` in N100 module. App ports via ansible firewalld, not baked.
7. Paths: ansible N100 profile uses `/var/home/{{runner}}`, `/var/lib/pihole`, `/etc/systemd`, `UserNS=auto`. Skip `apt`, skip `lan/networkd`, skip `iptables`.

## Plan (phased)

- Phase 0 doc (this file): record decisions + gaps.
- Phase 1 image: N100 server module, sysusers, sshd, firewall ssh, python3, polkit run0 rule, fcontext + restorecon on boot, linger.
- Phase 2 ansible: `inventories/n100/`, run0 become vars, ssh key var, selinux tasks (`sefcontext` + `restorecon`, `copy/template` with `seuser/setype`), firewalld per port. Test `ping` + `setup`, `run0 whoami`.
- Phase 3 pilot: one simple user quadlet (gotify/homepage first, pihole last: `NET_ADMIN` + `hostNetwork` = most AVCs). Reboot, verify `systemctl --user --machine=nimda@`, `podman ps`, `ausearch -m AVC -ts recent` clean.
- Non-goals: no sudo restore, no system quadlets, no baked app ports, no permissive, no NFS unless confirmed.
