## B. kmscon — migrated to system default (DONE)

F45 makes kmscon the default VT console ([Change/UseKmsconVTConsole](https://fedoraproject.org/wiki/Changes/UseKmsconVTConsole)): installed by default, `autovt@ → kmsconvt@` in `/usr/lib`, fallback to `getty`/`fbcon`.
`recipes/base/kmscon.yml` keeps the explicit installs (`kmscon`, `kmscon-gl`, `kmscon-pango` — all exist as `10.0.3-2.fc45`) plus the conf overlay; the manual `/etc/systemd/system/autovt@.service` symlink was **removed** — the system `/usr/lib` default now owns it. Base covers bare `kmscon`, but our `kmscon.conf` needs `hwaccel` (`-gl`) + `font-engine=pango` (`-pango`), which the default install does not include.
Remaining: diff `files/base/kmscon/etc/kmscon/kmscon.conf` against the new F45 sample (mouse/rotation/`kmscon-launch-gui`) at build time and adopt what's useful. No `setfont`/`loadkeys`/`gpm` usage in repo — verified clean.

## C. oo7 migration (DONE)

F45 switches the default Secret Service provider to oo7 ([Change](https://fedoraproject.org/wiki/Changes/oo7_Secrets_Service_Provider), `oo7-daemon 0.7.0~alpha-1.fc45`, auto-migrates legacy data). Do NOT install both providers — they race for `org.freedesktop.secrets` (cf. double-init fix in `next/2.1-boot_8745.md:32`).
Packaging verified via Fedora Packages file lists: `oo7-daemon` ships `oo7-daemon.service` + D-Bus activation (`dbus-org.freedesktop.secrets.service`, **no socket unit**); `oo7-portal` ships `oo7-portal.portal` + `oo7-portal.service`; `pam_oo7` ships `/usr/lib64/security/pam_oo7.so`.

## D. Other F45 evolutions (ranked)

1. **RPM signature enforcement** (`%_pkgverify_level all`, RPM 6.0/6.1): unsigned RPMs refuse install. Direct hit on Sunshine direct-URL pin — test first; prefer signed COPR.
2. **DNF5 `allow_vendor_change=False`**: the negativo17 `replace: from-repo: fedora-multimedia` (ffmpeg/mesa) is an intentional vendor switch — expect refusal without `--from-vendor=`/VendorChangeManager rule. Retest `5290` + `8745` video modules. Repo relocation (`/etc/yum.repos.d` → `/usr/share/dnf5/repos.d`) needs no action (only Brave `*.repo` URL, user-added path, unaffected; no repo overlays in `files/`).
3. **Podman 6**: drops slirp4netns/CNI/iptables-backend/cgroups-v1/BoltDB; `containers.conf` rework; `volume prune` skips named volumes; network isolation default on. Repo has no legacy refs. Touchpoints: (a) long-lived hosts on BoltDB must pass Podman 5.8 + reboot **before** rebasing (else state unreadable); retest `freellmapi` quadlet + `podman.socket`. (b) `files/wm/8745/etc/sysctl.d/70-bridge.conf` (`bridge-nf-call-iptables=0`) — re-verify `br0` behavior under nftables-only Netavark 2.0.
4. **OpenSSL 4.0** (landed, `4.0.1-5.fc45`, ENGINE removed): `tasks/cert/install` (`openssl s_client`) fine; watch the `pam_p11` source build (`next/1.1`). Containers isolated (Chainguard/Node, `pi` pins python `3.14.4` via `uv`).
5. **Python 3.15 + setuptools 82** (`pkg_resources` removed): host scripts trivial; risk is COPR Python packages FTBFS — covered by pre-flight build-status sweep.
6. **Toolchain GCC 16.2/glibc 2.44/binutils 2.47 + Shadow Stack**: runtime compat; watch source builds (`pam_p11`, `libflyline.so` in `non-packaged-tools.sh`, Hyprland COPR).
7. Verify-only: GNOME 51 portal stack (screenshot/screencast/filechooser), kernel 7.2 (suspend/hibernate, firmware), ptrace hardening (we already set `ptrace_scope=3` — confirm `gdb 17.2` flows), Go 1.27/LLVM 23/Perl 5.44 (rebuild-only), ISO task (`build-container-installer:v1.5.0` + `VERSION=45`, upstream moved to image-builder — confirm bootable), reproducible-builds/PURL (provenance only).
