### Fix worthy

1. [DONE 2026-09-17] `kernel: Malformed early option 'amd_pstate'`: root cause `amd_pstate=epp` in `recipes/cpu/amd.yml:19`. Valid values are only `disable/passive/active/guided` (kernel `amd-pstate.c` + `admin-guide/pm/amd-pstate`). Fixed to `amd_pstate=active`, preserves current `amd-pstate-epp` + `powersave` behavior observed on host (`/sys/devices/system/cpu/amd_pstate/status = active`). `mise run check:lint` passed.
2. `kvm_amd: [Firmware Bug]: Cannot enable x2AVIC, AVIC unsupported`: BIOS setting / firmware version. Check SVM/AVIC enable + BIOS update on 8745 box.
3. `systemd-logind[1168]: Failed to open '/boot/loader/entries': Remote address changed`: `/boot` mount race on composefs/bootc. Correlate with `files/base/system/usr/bin/firstboot:183-186` fstab root-comment logic and ESP/XBOOTLDR mounts.
4. `kernel: IPv4: martian destination (src=192.168.8.1, dst=0.0.0.0, dev=br0)`: bridge DHCP leak on `br0`. Check NetworkManager / container bridge config.
5. `thermal: failed to receive messages`: ACPI thermal zone missing. BIOS/firmware track only.
6. Post-boot group check needed: `getent group audio disk video render` + `getent passwd tss` to confirm sysusers resolves after switch-root; if missing, add `systemd-sysusers` overlay.
