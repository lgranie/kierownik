# Add score to bookmark launcher

## Goal

- Rank `/bookmarks` results by relevance score, not alphabetical.
- Score = fuzzy match (Title + URL + tags) + usage frequency boost.
- Host sorts by `score` desc; plugin must supply `score` per result.

## Context (verified)

- Plugin: `files/wm/common/noctalia/usr/lib/kierownik/noctalia/plugins/bookmarks/launcher.luau` (~320 lines). `plugin.toml:1-16` declares provider `bookmarks`, no score config needed.
- Host result type supports `score?: number`, ordered by score desc then insertion (`noctalia.d.luau` / Noctalia entry-scripts docs). `noctalia.fuzzyScore(pattern, text)` returns numeric score or nil.
- Linkding API (`/api/bookmarks/?format=json`) has no relevance score. Fields: `id, url, title, description, tag_names, date_added`. Score must be computed locally.
- Current behavior: `table.sort(keys)` alphabetical (~L262), `title:lower():find(lowerQuery)` substring (~L282), cap 50/100, no `score` field in `formatBookmark` (~L186-193).

## Changes

1. `launcher.luau` `parseBookmarks` (~L98-124): persist `id`, `url`, `date_added` alongside `tags`, `description`, `favicon_url`. Keep title-keyed `database` for compat with existing `database.json`. Usage key = `url` (fallback title) so renames survive re-fetch.
2. New usage store in `launcher.luau`: `local usage = {}`, `getUsagePath()` -> `<pluginDataDir>/usage.json`, `loadUsage()` / `saveUsage()` mirroring `loadDatabase`/`writeDatabase` (~L56-96). Shape: `{ [urlKey] = { count, last } }`. Missing file = count 0.
3. New `scoreBookmark(title, entry, query)`: `fuzzyScore` on title (x1.0), tags max (x0.8), url (x0.6); base = max non-nil, all nil = exclude. Boost = `math.log(1 + uses) * K + recency` (K ~20, +10 if `last` within 7d; calibrate, scale undocumented). Empty-query browse: score = usage boost only.
4. Rewrite `onQuery` filter/sort (~L245-287): keep category resolution + `showAll`; replace alphabetical sort + substring with score-all, drop nil, sort `score desc, title asc`, cap 50 search / 100 browse. Pass `score` in each result table.
5. Extend `formatBookmark(title, entry, score)` to include `score = score`.
6. `onActivate` (~L296-312): on bookmark launch, bump `usage[urlKey]`, `last = os.time()`, `saveUsage()`, then existing browser launch incl. `--app=` handling. Category path unchanged.
7. `plugin.toml:3`: bump `1.0.0` -> `1.1.0`.

## Verification

- `mise run check:lint`.
- Manual: `/bookmarks <query>` ordering; activate item 2-3x, re-query, confirm rise; `/bookmarks update` keeps `usage.json` counts; empty `/bookmarks` shows frequent first.
- `fuzzyScore` scale/case undocumented: try raw strings first, fallback lowered; log scores via `noctalia.log` to pick K.

## Decisions made

- Score source: usage frequency boost (not server search).
- Match fields: Title + URL + tags (description excluded).
